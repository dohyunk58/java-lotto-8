# java-lotto-precourse

우아한테크코스 8기 프리코스 3주차 과제 - 로또

## 고민했던 부분

1, 2주차 피드백과 3주차 요구 사항을 바탕으로 아래 규칙을 따르고자 노력했습니다.

1. 입력값 검증하기
2. 단일 책임 원칙 준수하기
3. 값을 하드코딩하지 않기
4. 기능 단위 테스트 작성하기

또한, 과제 진행중 리팩토링하면서 고민했던 부분은 아래와 같습니다.

1. 도메인의 유효성을 보장하도록 만들기
    입력값을 파싱하고 반환하는 유틸 객체에서 로또 가격은 1000원 단위, 번호는 1~45 범위, 중복 불가 등 모든 비즈니스 규칙(검증 로직)을 알고 있었습니다. 
    이로 인해 Lotto, PurchaseAmount 같은 핵심 도메인 객체들은 스스로의 유효성을 보장하지 못하는 상태에 놓였습니다. 이를 해결하기 위해 검증 책임을 주인인 도메인의 생성자로 이동시켰습니다.
2. 상수 관리
    과제를 수행하면서 1, 45, 6 과 같은 매직 넘버는 상수로 처리했습니다. 하지만 이 상수들이 여러 클래스에 중복되어 흩어져 있어 한 곳에서 상수 값을 바꾸면 다른 곳에서도 전부 바꿔야 했습니다.
    이를 해결하기 위해 LottoConfig 파일에 상수를 두어 유지보수성을 높였습니다.
3. 들여쓰기 뎁스 2 이하 규칙 준수를 위한 컨트롤러 리팩토링
    3주차 과제 내용 중 예외 발생 시 재입력 로직에 while-try-catch 구조를 사용하여 들여쓰기 뎁스가 3을 넘어가는 일이 발생했습니다.
    이를 해결하고자 힌트처럼 메서드 분리를 통해 while은 null인 경우만 반복하도록 하고 try-catch 구문을 메서드화했습니다.

## 기능 목록

### 1. 입력

- [x] 로또 구입 금액을 입력받는 기능
  - 예외 처리
  - [x] 구입 금액 입력값이 자연수가 아닌 경우(빈 문자열, 공백을 포함, 숫자가 아님, 실수, 0, 음수)
  - [x] 구입 금액 입력값이 1000으로 나누어 떨어지는 값이 아닌 경우
- [x] 6개의 당첨번호를 입력받는 기능
  - 예외 처리
  - [x] 당첨 번호 입력값이 쉼표로 나눌 수 없는 경우(빈 문자열, 공백을 포함)
  - [x] 당첨 번호 입력값을 쉼표로 나눈 결과가 6개가 아닌 경우
  - [x] 당첨 번호 입력값을 쉼표로 나눈 값이 정수가 아닌 경우(숫자가 아님, 실수 등)
  - [x] 당첨 번호 입력값을 나눈 값이 1부터 45 사이 정수가 아닌 경우
  - [x] 당첨 번호 입력값을 나눈 값 중에 중복되는 값이 있는 경우
- [x] 보너스 번호를 입력받는 기능
  - 예외 처리
  - [x] 보너스 번호 입력값이 정수가 아닌 경우(빈 문자열, 공백을 포함, 숫자가 아님, 실수)
  - [x] 보너스 번호 입력값이 1부터 45 사이 정수가 아닌 경우
  - [x] 보너스 번호 입력값이 당첨 번호 입력값과 중복되는 경우

### 2. 주요 로직

2-1. 로또 발행

- [x] 입력한 구입 금액을 1000원 단위로 나누어 로또 개수를 반환하는 기능
- [x] 1-45까지 중복되지 않는 6개의 로또 숫자를 뽑아 로또를 발행하는 기능
- [x] 로또 개수만큼 로또를 발행하는 기능

2-2. 로또 당첨 검증

- [x] 발행된 로또 번호와 당첨 번호를 비교하여 일치하는 숫자의 갯수를 세는 기능
- [x] 발행된 로또 번호와 보너스 번호를 비교하여 일치하는지 확인하는 기능

2-3. 통계 계산

- [x] 일치하는 숫자 개수와 보너스 번호 일치 여부로 당첨 등수를 결정하는 기능 
- [x] 등수에 따라 당첨 금액을 집계하는 기능
- [x] 집계된 당첨금액과 구매한 금액으로 수익률을 계산하는 기능

### 3. 출력

- [x] 구매한 로또 개수를 출력하는 기능
- [x] 발행된 로또 번호를 오름차순으로 출력하는 기능
- [x] 당첨된 로또의 수를 출력하는 기능
- [x] 총 수익률을 형식(소수점 둘째 자리 반올림)에 맞춰 출력하는 기능

### 4. 기능 외 요구사항

- [x] 들여쓰기 깊이 2 이하
- [x] 단일 책임 원칙을 지키도록 함수를 최대한 작게 만들기
- [x] 메서드 길이가 15를 넘지 않도록 구현하기
- [x] 구현한 기능의 단위 테스트 작성하기
