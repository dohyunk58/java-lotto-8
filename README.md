# java-lotto-precourse

우아한테크코스 8기 프리코스 3주차 과제 - 로또

## 기능 목록

### 1. 입력

- [ ] 로또 구입 금액을 입력받는 기능
- [ ] 1-45까지 중복되지 않는 6개의 당첨번호를 입력받는 기능
- [ ] 1-45까지 당청번호와 중복되지 않는 보너스 번호를 입력받는 기능

### 2. 주요 로직

2-1. 로또 발행

- [ ] 입력한 구입 금액을 1000원 단위로 나누어 로또 개수를 반환하는 기능
- [x] 1-45까지 중복되지 않는 6개의 로또 숫자를 뽑아 로또를 발행하는 기능
- [x] 로또 개수만큼 로또를 발행하는 기능

2-2. 로또 당첨 검증

- [x] 발행된 로또 번호와 당첨 번호를 비교하여 일치하는 숫자의 갯수를 세는 기능
- [x] 발행된 로또 번호와 보너스 번호를 비교하여 일치하는지 확인하는 기능

2-3. 통계 계산

- [x] 일치하는 숫자 개수와 보너스 번호 일치 여부로 당첨 등수를 결정하는 기능 
- [x] 등수에 따라 당첨 금액을 집계하는 기능
- [x] 집계된 당첨금액과 구매한 금액으로 수익률을 계산하는 기능

### 3. 출력

- [ ] 구매한 로또 개수를 출력하는 기능
- [ ] 발행된 로또 번호를 오름차순으로 출력하는 기능
- [ ] 당첨된 로또의 수를 출력하는 기능
- [ ] 총 수익률을 형식(소수점 둘째 자리 반올림)에 맞춰 출력하는 기능

### 4. 예외 처리

4-1. 구입 금액 입력값

- [x] 구입 금액 입력값이 자연수가 아닌 경우(빈 문자열, 공백을 포함, 숫자가 아님, 실수, 0, 음수)
- [x] 구입 금액 입력값이 1000으로 나누어 떨어지는 값이 아닌 경우

4-2. 당첨 번호 입력값

- [x] 당첨 번호 입력값이 쉼표로 나눌 수 없는 경우(빈 문자열, 공백을 포함)
- [x] 당첨 번호 입력값을 쉼표로 나눈 결과가 6개가 아닌 경우
- [x] 당첨 번호 입력값을 쉼표로 나눈 값이 정수가 아닌 경우(숫자가 아님, 실수 등)
- [x] 당첨 번호 입력값을 나눈 값이 1부터 45 사이 정수가 아닌 경우
- [x] 당첨 번호 입력값을 나눈 값 중에 중복되는 값이 있는 경우

4-3. 보너스 번호 입력값

- [ ] 보너스 번호 입력값이 정수가 아닌 경우(빈 문자열, 공백을 포함, 숫자가 아님, 실수)
- [ ] 보너스 번호 입력값이 1부터 45 사이 정수가 아닌 경우
- [x] 보너스 번호 입력값이 당첨 번호 입력값과 중복되는 경우
